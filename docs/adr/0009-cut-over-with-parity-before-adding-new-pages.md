# Cut over with parity before adding new pages

The first production release will migrate the existing public surface to TanStack Start, MDX, Effect-backed content tooling, and Cloudflare deployment while preserving its routes, content, and design. It will prove interactive MDX, protected draft previews, and the R2 image pipeline, but new products such as `/now`, `/uses`, search, comments, or a CMS will follow the successful cutover. This limits the number of unfamiliar systems that must be diagnosed simultaneously and preserves the current deployment as a rollback target.
