# Use Effect at effectful boundaries

Effect will model the content pipeline, metadata and runtime-data validation, R2 access, typed infrastructure failures, retries, and testable service dependencies. Build commands and TanStack server functions or loaders will execute these programs and pass ordinary values into React. Pure transformations and component state will remain idiomatic TypeScript and React, keeping Effect concentrated where its error and dependency model teaches useful lessons instead of adding ceremony throughout the UI.
