# Adopt MDX as the native post format

Existing posts will receive a one-time reviewed conversion to MDX rather than requiring compatibility with every behavior of the current Mistune renderer. Public URLs and substantive content will remain stable, while renderer-specific markup may become explicit reusable post components for notes, images, figures, and future interactive material. Treating MDX and those components as the native authoring vocabulary keeps new posts aligned with React instead of carrying the old rendering model forward.
